# Test Demo - S3 Bucket Infrastructure

This repository contains Terraform configuration for creating and managing AWS S3 buckets with comprehensive features.

## 📁 Project Structure

```
terraform/
├── providers.tf           # AWS provider configuration
├── variables.tf          # Input variables
├── main.tf              # S3 bucket resources
├── outputs.tf           # Output values
└── terraform.tfvars.example  # Example variable values
```

## 🚀 Features

- **S3 Bucket Creation** with globally unique naming
- **Versioning** support (enabled by default)
- **Server-side encryption** with AES256
- **Public access blocking** for security
- **Lifecycle management** with configurable rules
- **CORS configuration** support
- **Event notifications** (Lambda, SNS, SQS)
- **Comprehensive tagging** strategy

## 🛠️ Prerequisites

- Terraform >= 1.0
- AWS CLI configured with appropriate credentials
- AWS IAM permissions for S3 operations

## 📝 Usage

### 1. Clone the Repository

```bash
git clone https://github.com/PrakashNexTurn/test-demo.git
cd test-demo
```

### 2. Configure Variables

Copy the example variables file and customize it:

```bash
cp terraform/terraform.tfvars.example terraform/terraform.tfvars
```

Edit `terraform.tfvars` with your desired configuration:

```hcl
aws_region  = "us-east-1"
environment = "dev"
bucket_name = "my-unique-bucket-name"  # Optional, auto-generated if null
versioning_enabled = true
```

### 3. Initialize and Deploy

```bash
cd terraform

# Initialize Terraform
terraform init

# Plan the deployment
terraform plan

# Apply the configuration
terraform apply
```

### 4. Clean Up (Optional)

```bash
terraform destroy
```

## 📋 Configuration Options

### Basic Configuration

| Variable | Description | Type | Default |
|----------|-------------|------|---------|
| `aws_region` | AWS region for resources | string | `us-east-1` |
| `environment` | Environment name | string | `dev` |
| `bucket_name` | S3 bucket name (must be globally unique) | string | `null` (auto-generated) |
| `versioning_enabled` | Enable S3 versioning | bool | `true` |
| `force_destroy` | Allow bucket deletion with objects | bool | `false` |

### Advanced Configuration

- **Lifecycle Rules**: Configure object expiration and transitions
- **CORS Rules**: Set up cross-origin resource sharing
- **Event Notifications**: Configure Lambda, SNS, or SQS notifications
- **Custom Tags**: Add additional metadata tags
